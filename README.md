# Ateliê Oliveira

* Site de catálogo e pedidos do Ateliê Oliveira. O catálogo e os preços são carregados de uma planilha; o cliente pode adicionar produtos ao carrinho e enviar o pedido pelo WhatsApp.

* O que o site oferece

* Catálogo separado por disponibilidade e categoria.

* Destaque para produtos em oferta.

* Fotos, descrições e preços carregados da planilha.

* Cards que podem ser virados para exibir a descrição do produto.

* Carrinho com ajuste de quantidade e remoção de produtos.

* Formulário para enviar o pedido pelo WhatsApp.

* Menu com acesso às categorias e à página “Sobre nós”.

* Arquivos e serviços

* index.html: estrutura, estilos e funcionalidades do site.

* logo.jpg: imagem inicial exibida no topo da página.

* Google Sheets: fornece os dados dos produtos e as URLs das imagens.

* Google Drive: hospeda as fotos dos produtos, conforme os links cadastrados na planilha.

* WhatsApp: recebe os pedidos enviados pelo site.

* O site precisa de conexão com a internet para carregar os dados e as imagens da planilha e abrir o WhatsApp.
